Application Windows portable pour convertir les PDF vectoriels compatibles en PLT pour Lasertrace.

- Interface en français : sélection du PDF, dossier de sortie et pas de remplissage.
- Traits épais développés en contours, extrémités arrondies et remplissage par balayage.
- Exports PLT rempli, PLT de contours, DXF, PDF de surfaces et SVG.
- Conversion à l’échelle d’origine ; confirmation avant remplacement de fichiers.
- Exécutable compilé et testé sur les runners Windows de GitHub Actions.

Télécharger **PDF_to_PLT.exe** ou le ZIP Windows. Aucun Python n’est nécessaire.
Lire le README pour les limites du lecteur PDF et les réglages d’import Lasertrace.
